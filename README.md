# vinter-odin

Cross Platform Game Engine written in Odin.

Meant as a prototyping playground for my main [C++ vinter project](https://github.com/panagiotisu/vinter).

## Overview

vinter-odin mirrors the architecture of the C++ vinter engine, using Odin as a faster iteration environment for experimenting with engine systems before promoting them upstream.

Built on top of [SDL3](https://wiki.libsdl.org/SDL3/FrontPage) via Odin's vendor bindings.
